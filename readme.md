
# Laboratorio di Internet – Esercitazioni in Java

Questa repository raccoglie esercitazioni svolte durante il corso di **Laboratorio di Internet** presso il Politecnico di Torino.  
Il corso è incentrato sull'analisi retistica con focus su:

## 🌐 Argomenti principali

- Analisi dei socket (TCP/UDP)
- Comunicazione client-server
- Analisi di traffico (con WireShark)
- Analisi dei risultati utilizzando il bash

## 📁 Struttura della repository

- Cartelle 'Lab01, Lab02, ...' contengono i dati, gli script e le relazioni
- README di riferimento (questo file)

> ⚠️ I testi ufficiali degli esercizi non sono inclusi, in rispetto alle politiche dell’ateneo.

Questa repository è a scopo **personale e didattico**. Tutto il codice presente è scritto da me durante lo studio individuale e le attività di laboratorio.
